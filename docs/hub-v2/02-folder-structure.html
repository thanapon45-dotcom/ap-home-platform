วางโค้ดที่ไหน

  • กฎธุรกิจอยู่ใน domain/use case; ไม่ให้ผูกกับ HTTP หรือ provider โดยตรง
  • สัญญาระหว่าง use case กับบริการภายนอกอยู่ใน ports และ implementation อยู่ infrastructure
  • HTTP validation/auth/response อยู่ presentation
  • server.ts ประกอบ dependencies; server.cjs ของ v1 ยังเป็นอีก implementation หนึ่ง ไม่ถือว่าลบออกได้ทันที

สถานะการย้าย

v2 ใช้ x-hub-secret ต่างจาก v1 x-hub-token; Blog queue มี route แล้ว แต่ FB queue ยังไม่ครบใน fbRoutes.ts การมี folder ครบไม่ยืนยัน API parity หรือ cutover สำเร็จ

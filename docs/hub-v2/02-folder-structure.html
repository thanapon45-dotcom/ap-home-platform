4 TypeScript Path Aliases

tsconfig.json กำหนด aliases เพื่อหลีกเลี่ยง ../../../../../../

AliasMaps toใช้ใน
@core/*src/core/*ทุก layer ที่ import domain/application
@modules/*src/modules/*presentation → modules
@infra/*src/infrastructure/*server.ts bootstrap เท่านั้น
@presentation/*src/presentation/*server.ts router mounting
@shared/*src/shared/*ทุก layer
⚠️ Rule: @core ห้าม import @infra หรือ @modules เด็ดขาด — ถ้า import ข้ามทิศ → CI จะ fail (เพิ่ม eslint-plugin-import rule)

5 What Goes Where — Decision Guide

ต้องการเพิ่ม...ใส่ไว้ที่เหตุผล
Business rule ใหม่ (เช่น QC scoring logic)core/domain/entities/Pure logic — testable without I/O
Use case ใหม่ (เช่น RenewFbTokenUseCase)core/application/use-cases/Orchestrates domain + calls ports
AI provider ใหม่modules/ai-gateway/providers/Implements IAiProvider
External service ใหม่ (เช่น Notion)infrastructure/notion/Adapter — implements port interface
HTTP route ใหม่presentation/routes/ + controllers/Thin layer — parse/respond only
Utility function ใช้หลายที่shared/No domain knowledge
Business event ใหม่core/domain/events/Immutable data record
Health check ใหม่modules/health-center/checks/IHealthCheck interface

  3. NAMING CONVENTIONS
================================================================================

  FILE / FOLDER NAMES
  ───────────────────
  Entity          →  BlogRun.ts
  Interface(Port) →  IAiProvider.ts          (prefix I)
  Use Case        →  RunBlogUseCase.ts
  Controller      →  BlogController.ts
  Repository      →  SupabaseStateRepository.ts
  Middleware      →  auth.middleware.ts       (kebab-case)
  Routes          →  blog.routes.ts           (kebab-case)
  Adapter         →  N8nWorkflowAdapter.ts
  Event           →  BlogRunStarted.ts
  Test            →  BlogRun.test.ts

  CODE STYLE
  ──────────
  Class           →  PascalCase
  Interface       →  PascalCase (prefix I)
  Function        →  camelCase
  Constant        →  SCREAMING_SNAKE_CASE
  Private field   →  _camelCase (prefix _)
  Type alias      →  PascalCase
  Enum            →  PascalCase
  Folder          →  kebab-case
  Barrel export   →  index.ts in module root


================================================================================
  4. TYPESCRIPT PATH ALIASES  (tsconfig.json)
================================================================================

  Alias               Maps to                     ใช้ใน
  ─────────────────────────────────────────────────────────────────────────────
  @core/*             src/core/*                  ทุก layer ที่ import domain
  @modules/*          src/modules/*               presentation → modules
  @infra/*            src/infrastructure/*        server.ts bootstrap เท่านั้น
  @presentation/*     src/presentation/*          server.ts router mounting
  @shared/*           src/shared/*                ทุก layer

  ⚠️  RULE: @core ห้าม import @infra หรือ @modules เด็ดขาด
            ถ้า import ข้ามทิศ → CI fail (eslint-plugin-import rule)


================================================================================
  5. WHAT GOES WHERE — DECISION GUIDE
================================================================================

  เมื่อต้องการเพิ่ม...                        ใส่ที่                                เหตุผล
  ─────────────────────────────────────────────────────────────────────────────
  Business rule ใหม่ (QC scoring logic)  core/domain/entities/           Pure logic — testable
  Use case ใหม่ (RenewFbTokenUseCase)    core/application/use-cases/     Orchestrates domain+ports
  AI provider ใหม่                       modules/ai-gateway/providers/   implements IAiProvider
  External service ใหม่ (Notion)         infrastructure/notion/          Adapter — implements port
  HTTP route ใหม่                        presentation/routes/ + ctrl/    Thin parse/respond only
  Utility ใช้หลายที่                     shared/                         No domain knowledge
  Business event ใหม่                    core/domain/events/             Immutable data record
  Health check ใหม่                      modules/health-center/checks/   IHealthCheck interface

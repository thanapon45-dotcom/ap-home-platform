เอกสารทั้งหมด ภาพรวมสถานะ
ยืนยันเส้นทางจากโค้ดและ ADR ณ commit ที่ระบุ การมีโค้ดไม่ยืนยันว่า deployment, credentials และ workflow ที่ active ทำงานครบแล้ว รอบนี้ไม่ได้รันงาน production

เลือกเส้นทางเพื่อดูทีละขั้น

ทุกเส้นทางสำหรับอ่านและพิมพ์

อ่านภาพรวม
01 · Dashboard เรียก /api/leads สำหรับ lead และ /api/blog/state สำหรับ engine state
02 · API อ่าน Supabase หรือ Hub /api/state ตามประเภทข้อมูล
03 · หน้าเว็บแสดงผล; API error ต้องตรวจแยกจากไม่มีข้อมูล
สร้างบทความ
01 · ผู้ใช้สั่งผ่าน /marketing หรือ schedule ที่ตั้งใน n8n
02 · Next.js proxy เรียก Hub /action/blog/queue/run-next; Assistant ใช้ /action/blog/run เมื่อระบุ keyword
03 · Hub เรียก WF1; ลำดับ writer/guard/gate ต้องตรวจ active export
04 · ทางผ่านเผยแพร่ WordPress; ทางบล็อกแจ้งเหตุผล; callback กลับ Hub ต้องสัมพันธ์ run ID
05 · ตรวจ quality_gate_log และ human feedback แยกจากเพียงสถานะ execution สำเร็จ
Facebook ทันที / Queue
01 · AI Content เรียก /api/chat และ /api/image ตามงานที่เลือก
02 · ผู้ใช้ตรวจข้อความ รูป และข้อมูลก่อนสั่งเผยแพร่
03 · โพสต์ทันที: /api/fb/publish → FB Backend → Facebook
04 · Queue: /api/fb/queue/* → Hub v1 → กลไกเผยแพร่ของ queue
05 · ตรวจผลโพสต์จริงก่อน retry ไม่อนุมานว่ารับ request แล้วโพสต์สำเร็จ
ดีลและงานก่อสร้าง
01 · สร้างดีลด้วยฟอร์ม /deals → /api/deals → reno_deals
02 · เลือก site_id เมื่อมี site จริง; QC ใช้ deal_id/site_id เชื่อมเมื่อบันทึกไว้
03 · แก้ stage และต้นทุนจริงผ่าน /api/deals/[id]
04 · Brains อ่านข้อมูลดีล/QC มาประกอบการตอบ แต่ไม่รวม Land Project เป็นดีลเดียวกันเอง
ถาม Assistant
01 · ข้อความ + ประวัติหน้าเว็บ → /api/assistant → Claude
02 · โมเดลเลือก tools อ่าน Hub, Supabase หรือ Brains
03 · ถ้าเป็น run_blog_now หรือ run_fb_queue_next ให้ UI ขอการยืนยัน
04 · ผล tool กลับไปให้โมเดลเขียนคำตอบ; prompt ห้ามข้อมูลนอกระบบยังไม่ใช่การตรวจหลักฐานเชิงบังคับ
05 · reload หน้าเว็บแล้วไม่มีการกู้แชทถาวร; ไม่มี tool บันทึกดีลจากข้อความ
Market Intelligence
01 · ผู้ใช้ส่ง text / area / timing ผ่าน /api/market-intel
02 · Next.js ส่งต่อ webhook ของ n8n ตาม env
03 · Collector ตาม ADR เขียน market_insights, buyer_context_signals, content_frames และส่งผลตาม workflow
04 · ตรวจ execution และข้อมูลที่เขียนจริง; Brains อ่านต่อเมื่อมี record แล้ว
05 · Human calibration บันทึกความถูก/ผิด ไม่ได้ retrain อัตโนมัติ

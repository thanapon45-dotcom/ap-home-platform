ขอบเขตฉบับนี้

  • แก้เนื้อหาเก่าเรื่อง Budget, เวลา/สถานะ workflow, FB token, Hub routing และความสัมพันธ์ Land/Deals

  • ไม่ได้แก้ runtime, active n8n workflow, database หรือรับรอง deployment
  • ข้อเสนอใน Roadmap ยังเป็นงานที่ต้องทำ ไม่ใช่สถานะเสร็จ

เอกสารทั้งหมดภาพรวมสถานะ
ยืนยันเส้นทางจากโค้ดและ ADR ณ commit ที่ระบุ การมีโค้ดไม่ยืนยันว่า deployment, credentials และ workflow ที่ active ทำงานครบแล้ว รอบนี้ไม่ได้รันงาน production

ธุรกิจเป็นศูนย์กลาง

Fix & Flip / Develop 60% · ที่ปรึกษาและตรวจสอบ 30% · นายหน้า 10% เป็นสัดส่วนธุรกิจตามเอกสาร ไม่ใช่ยอดรายได้ที่ดึงจากฐานข้อมูล

ให้ความรู้เรื่องสร้างบ้านได้ แต่ห้ามอ้างว่า Finnhouses รับจ้างสร้างบ้านให้ลูกค้า การพัฒนาทรัพย์ของบริษัทเพื่อขายเป็นอีกกรณีหนึ่ง

การตลาดและขาย

  • CRM — lead และการติดตาม
  • Content / Blog / FB — สร้าง ตรวจ และเผยแพร่
  • Properties — รับทรัพย์และตรวจข้อมูล
  • Market Intel — ข้อมูลตลาดและ calibration

การลงทุนและก่อสร้าง

  • Land Analyzer — Build-to-Sell → projects
  • Deals — Renovate-to-Resell → reno_deals
  • BOQ — ปริมาณและต้นทุน
  • QC — ผลตรวจ + feedback; เชื่อม site/deal เมื่อมี ID

ข้อมูลและผู้ช่วย

  • Supabase — records และ views
  • Brains — รวมข้อมูลเดิมแบบอ่านอย่างเดียว
  • Assistant — เลือก tools และสรุป; ยังไม่มีความจำแชทถาวร
  • Human feedback — ประเมินความถูกต้อง ไม่ใช่ retraining

บริการที่ทำให้ระบบเดิน

  • Next.js — UI + API หลายปลายทาง
  • Hub v1 — orchestration / queues / QC / BOQ
  • FB Backend — โพสต์ตรงจาก Content Studio
  • n8n — workflows; active revision ต้องตรวจ
  • Hub v2 — โครงสร้างแยก; ยังไม่ cutover ครบ

สิ่งที่ยังต้องพัฒนา

  • ยืนยัน active WF1 ใช้ policy ที่แก้แล้วและวัดผลก่อน/หลัง
  • บังคับ Assistant ตอบจากหลักฐานภายในให้ครบ; ไม่พึ่ง prompt อย่างเดียว
  • ความจำถาวรที่แยกดีลจริงจากสมมติฐาน
  • บัญชี usage และเพดานงบ AI ร่วมทุก provider/เส้นทาง
  • ทดสอบ API compatibility ก่อนย้าย v2

ค่าใช้จ่าย

ยอดผู้ใช้แจ้ง $20–25/เดือน (OpenAI $5, Claude $5, Railway $10–15); n8n แบบฟรี ไม่ใช่ยอดที่ตรวจ billing หรือ hard cap ปัจจุบัน

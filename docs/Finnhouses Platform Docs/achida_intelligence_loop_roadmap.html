Intelligence Loop Roadmap

แผนพัฒนาตามช่องว่างจริง โดยไม่ถือว่า roadmap เดิมเสร็จแล้ว

ทบทวน 22 กันยายน 2026 · อ้างอิง main 1dddb46

เอกสารทั้งหมดภาพรวมสถานะ
ยืนยันเส้นทางจากโค้ดและ ADR ณ commit ที่ระบุ การมีโค้ดไม่ยืนยันว่า deployment, credentials และ workflow ที่ active ทำงานครบแล้ว รอบนี้ไม่ได้รันงาน production

ฐานที่มีอยู่และสิ่งที่ยังขาด

Fix & Flip / Develop 60% · ที่ปรึกษาและตรวจสอบ 30% · นายหน้า 10% เป็นสัดส่วนธุรกิจตามเอกสาร ไม่ใช่ยอดรายได้ที่ดึงจากฐานข้อมูล

ให้ความรู้เรื่องสร้างบ้านได้ แต่ห้ามอ้างว่า Finnhouses รับจ้างสร้างบ้านให้ลูกค้า การพัฒนาทรัพย์ของบริษัทเพื่อขายเป็นอีกกรณีหนึ่ง

ลำดับมีในโค้ด/เอกสารแล้วงานถัดไปหลักฐานก่อนปิดงาน
1 · ข้อมูลและ workflowCRUD, queue, Quality Gate/QC feedbackยืนยัน active workflow และแก้ผลบล็อกผิดexport revision + execution + ผลตรวจบทความเต็ม
2 · เชื่อมบริบทBrains รวม market/deals/QC/contentเติมความสัมพันธ์เฉพาะเมื่อมี ID จริงไม่เดา project↔deal; ทดสอบ filter และข้อมูลว่าง
3 · ผู้ช่วยวิเคราะห์Assistant อ่าน tools; กฎ internal-only ใน promptบังคับหลักฐาน คำนวณที่ตรวจย้อนกลับได้ แยก what-ifคำตอบอ้าง record/เวลาได้; ไม่เติมตัวเลขนอกระบบ
4 · ความจำและต้นทุนประวัติชั่วคราว; usage เฉพาะบางระบบออกแบบ memory และ budget accounting ร่วมreload กู้ได้ตามสิทธิ์; usage ครอบคลุม retry/ภาพ/n8n
5 · วงจรปรับปรุงมี human feedback และ actual deal fieldsใช้ชุดประเมินก่อนเปลี่ยน prompt/modelผลก่อน/หลัง ชุดทดสอบที่แยกจากชุดปรับ และ rollback

ความหมายของ Intelligence Loop

เก็บข้อมูลจริง → ตรวจคุณภาพและความสัมพันธ์ → วิเคราะห์ด้วยหลักฐาน → มนุษย์ตัดสินใจ → เก็บผลจริงเพื่อประเมินรอบต่อไป ขณะนี้มีชิ้นส่วนของวงจร แต่ยังไม่ควรระบุว่าระบบปรับตัวเองอัตโนมัติครบสาย

Hub v2 เป็นงานอีกด้านหนึ่ง

การเปลี่ยนโครงสร้าง backend ช่วยบำรุงรักษา แต่ไม่ใช่เงื่อนไขว่าต้องย้าย v2 ก่อนจึงทำผู้ช่วยวิเคราะห์ได้ ต้องประเมินงานด้านหลักฐาน ข้อมูล สิทธิ์และต้นทุนแยกจากงานย้าย API

ข้อกำหนดที่ต้องรักษา

  • ไม่กลับไปอ้างว่าธุรกิจรับจ้างสร้างบ้าน; Content ให้ความรู้ยังทำได้
  • ไม่รวม Land Project กับ Fix & Flip Deal เอง
  • ไม่ถือ feedback เป็นคำสั่ง retrain หรือ publish อัตโนมัติ
  • ไม่มีเปอร์เซ็นต์ความพร้อม วันที่เสร็จ หรือต้นทุนประหยัดที่ยังไม่ได้วัด

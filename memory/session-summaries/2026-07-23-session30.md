### 2. Bug จริงที่เจอระหว่างตรวจกราฟ — `useLiveData()` bypass Hub auth
- `components/DashboardOS.tsx`'s `useLiveData()` ยิง `fetch(NEXT_PUBLIC_HUB_URL + "/api/state")` ตรงจาก browser ไม่มี `x-hub-token`
- ตรวจ `server.cjs` (บรรทัด 578-593) ยืนยัน Hub v1 มี global auth middleware → fetch นี้โดน 401 ทุกครั้ง = **ไม่ใช่ data leak** แต่เป็น **functional bug**: `setData()` ไม่เคยถูกเรียกเมื่อ fail → dashboard โชว์ MOCK ค้างตลอดกาลมาตั้งแต่แรก
- แก้: เปลี่ยนไปเรียก `/api/blog/state` (proxy ที่มีอยู่แล้ว ใช้จริงโดย Marketing.tsx) แทน + เช็ค `json?.error`
- Verify: `npx tsc --noEmit` ผ่านสะอาด, ตรวจ shape จริงของ Hub state (`baseState()`) ก่อนแก้ ยืนยันไม่มีความเสี่ยง field undefined
- รายละเอียดเต็ม: `docs/issues-log.md` ISSUE-017, `docs/decisions.md` ADR-024
